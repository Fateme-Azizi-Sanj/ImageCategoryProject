# پروژه دسته‌بندی تصاویر

این پروژه با زبان پایتون، از هر دسته‌بندی تصویر (مانند طبیعت، غذا و خیابان) به‌صورت تصادفی یک تصویر را انتخاب کرده و نسخه‌ی رنگی، خاکستری و محوشده آن را نمایش می‌دهد.

## پیش‌نیازها
- Python 3
- کتابخانه‌های opencv-python و matplotlib
